🚀 Featured Projects

🎮 "ProtonHook" (https://github.com/SitHond/ProtonHook)

Run Windows game trainers on Linux and Steam Deck through Proton.

ProtonHook automatically detects Steam games and their Proton environments, allowing Windows trainers to run alongside games without manually configuring Wine prefixes.

- Automatic Steam game and Proton prefix detection
- GTK graphical interface
- Built-in diagnostics and troubleshooting
- Proton prefix backup and restoration
- Decky Loader integration for Steam Deck

"Python" "Linux" "Proton" "GTK" "Steam Deck"

🎬 "ShikiRIP Cinema" (https://github.com/SitHond/shikicinema)

Bringing anime streaming functionality back to Shikimori.

A browser extension designed to enhance the anime-watching experience on Shikimori.

Features include video playback integration, watch progress tracking, and additional functionality for anime enthusiasts.

"JavaScript" "Browser Extensions" "Web"
